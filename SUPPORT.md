# Support

## Before you ask

Most questions are answered in one of these:

1. [docs/FAQ.md](docs/FAQ.md) — nothing is drawn, sessions are an hour off, missing history, labels, dashboard.
2. [docs/SETTINGS.md](docs/SETTINGS.md) — what each input does, with pictures of the modules.

## Where to ask

| You have | Go to |
| ---------- | ------- |
| A bug | [New issue → Bug report](https://github.com/DmytroPalahin/sessions-indicator/issues/new/choose) |
| An idea | [New issue → Feature request](https://github.com/DmytroPalahin/sessions-indicator/issues/new/choose) |
| A short question about using the indicator | The comments under the [TradingView publication](https://www.tradingview.com/script/aK5XyDPb-Sessions-Killzones-Opening-Range-and-Dashboard-with-Auto-DST/) |
| A security problem | [SECURITY.md](SECURITY.md) |

## What to include

A report with these details can usually be answered in one reply:

- the **symbol** with its exchange prefix, for example `FX:EURUSD`;
- the **chart timeframe**;
- the **timezone** selected in *① General → Timezone of session times*;
- which **modules** are on, and any session time you changed;
- a **screenshot** of the chart and, for errors, the exact text of the message;
- the indicator **version** — the `VERSION` line at the top of the script, or, if you added the indicator from
  TradingView, the date of the latest update shown on its page.

## What this project does not offer

- Trading advice or signals.
- Help with other indicators.
- Private or paid support.
